# Contributing to T Code

Thanks for helping improve T Code. T Code is a lightweight text editor written
in Lua on top of a small C core.

## Reporting issues

Please report bugs and feature requests through
[thinakaran.dev](https://thinakaran.dev/). Include the T Code version (visible
on the welcome screen or in **Help → About T Code**), your operating system,
and the steps needed to reproduce the issue.

## Plugins and themes

Most additional functionality belongs in a plugin. T Code remains compatible
with most Lite XL plugins and color themes:

- [Lite XL plugins](https://github.com/lite-xl/lite-xl-plugins)
- [Lite XL color themes](https://github.com/lite-xl/lite-xl-colors)

## Contributing code

1. Fork the repository and create a branch for your change.
2. Build T Code using the instructions in [README.md](README.md#quick-build-guide).
3. Keep changes focused and consistent with the surrounding code style.
4. Test the editor before opening a pull request.
5. Open a pull request describing what changed and why.
